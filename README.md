A hands-on, project-based path to Python and Machine Learning mastery — **52 projects**.

I divided it into 5 levels:

| Level | Focus | Projects |
|---|---|---|
| 🧱 [Fundamentals](#-fundamentals) | Core syntax, data validation | 1–10 |
| 🧩 [Core Python & OOP for ML Code](#-core-python--oop-for-ml-code) | Classes, dataclasses, generators | 11–20 |
| 📊 [NumPy, Pandas & Data Analysis](#-numpy-pandas--data-analysis) | Vectorization, cleaning, EDA | 21–30 |
| 🤖 [Classical ML with scikit-learn](#-classical-machine-learning-with-scikit-learn) | Models, evaluation, pipelines | 31–40 |
| 🧠 [Deep Learning, NLP & Applications](#-deep-learning-nlp--real-world-ml-applications) | PyTorch, NLP, deployment | 41–52 |
